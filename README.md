# Widget Workshop: Android App Development for Students

A playful, interactive landing page that explains **Android app development for students**, **Flutter widgets** and **app design** in simple language for kids and parents.

Tap widget bricks to build a play phone screen, switch between Row, Column and Stack layouts, see the difference between stateless and stateful widgets, and learn four friendly app design rules.

## What is inside

* A play phone builder with Text, Image, Button, Progress bar and Counter widgets
* A Row, Column and Stack layout playground
* A stateless and stateful widget demo
* Four app design rules for beginners
* Clickable cards and a footer with all learning links
* Fully responsive layout, keyboard friendly focus states and reduced motion support

## Run it locally

No build step is needed. Download the repository and open `index.html` in any modern browser.

## Publish on GitHub Pages

1. Push `index.html` and `README.md` to the `main` branch.
2. Open **Settings**, then **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and the `/ (root)` folder, then save.
4. Your page will be live at `https://YOUR-USERNAME.github.io/flutter-widgets-app-design-for-students/`.
